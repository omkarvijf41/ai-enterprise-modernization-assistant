# 4-minute portfolio demo

1. Open the Angular workbench and point out the prefilled synthetic Claims Portal example.
2. Click **Generate engineering brief**.
3. Walk through modernization opportunities, security review prompts, cloud migration considerations and suggested next steps.
4. Explain that `demo` mode uses deterministic heuristics; it does not call a vulnerability database or inspect source code.
5. Configure Azure OpenAI in the backend environment to demonstrate the optional model path. Never expose the API key in a screen recording.
6. Close with the roadmap: identity, approved scanner integrations, retrieval with citations, auditability, evaluation and human approvals.

## Suggested narration
“This prototype explores how an engineering team could turn a lightweight application inventory into a repeatable modernization conversation. It deliberately does not claim to scan source code or confirm vulnerabilities. The value is in organizing the questions, evidence and next decisions before teams commit to a migration.”
